Sou **ScarterDM**, programador e criador de plugins, especializado no desenvolvimento da **família TD** para o meu próprio servidor, a **Trindade Craft**.

Transformo as necessidades da comunidade em sistemas próprios: administração, interação social, magia, identidade visual e experiências de jogo. Meu foco é construir projetos organizados, modulares e preparados para evoluir junto com o servidor.

## Desenvolvimento personalizado

Interessado em um plugin para o seu servidor? Procure **ScarterDM**, pelos canais oficiais da Trindade Craft, para conversar sobre as necessidades do projeto e solicitar um **orçamento personalizado**.

## Como os projetos evoluem

**DEV** identifica trabalho em desenvolvimento e testes. **OFICIAL** identifica uma versão aprovada por mim para uso na Trindade Craft. A apresentação pública não inclui downloads de plugins.
